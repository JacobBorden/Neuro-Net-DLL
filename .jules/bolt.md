## 2026-10-07 - Matrix Multiplication Cache Locality
**Learning:** In `src/neural_network/neuronet.cpp`, the matrix multiplication within `NeuroNetLayer::CalculateOutput()` suffers from severe CPU cache misses when using the standard `(i, j, k)` loop order because of column-major memory access of `WeightMatrix[k][j]`. Reordering the loops to `(i, k, j)` resolves this by allowing contiguous, row-major access to both `OutputMatrix[i][j]` and `WeightMatrix[k][j]`, which yields substantial performance gains and auto-vectorization benefits.
**Action:** When implementing matrix multiplications in C++, always verify the memory layout (e.g., row-major arrays of pointers) and structure the innermost loop to access elements consecutively in memory to avoid severe cache performance penalties.
