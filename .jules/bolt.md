## $(date +%Y-%m-%d) - [Optimize Matrix Multiplication Cache Locality]
**Learning:** The C++ row-major matrix implementation (`Matrix::Matrix<T>`) had a performance bottleneck in matrix multiplication (`operator*`) due to inefficient loop ordering. The naive `i-k-j` loop resulted in poor cache locality when accessing elements of `B`, causing frequent cache misses. Switching to an `i-j-k` loop interchange ensures that both `A` and `B` are accessed sequentially in memory, drastically improving cache utilization.
**Action:** When implementing mathematical operations on row-major matrices, always prioritize loop structures that maximize sequential memory access (like the `i-j-k` ordering for matrix multiplication) to minimize cache misses and improve overall execution speed.
