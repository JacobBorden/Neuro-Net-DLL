## $(date +%Y-%m-%d) - Matrix Multiplication Cache Locality Optimization
**Learning:** In C++ multi-dimensional array or matrix evaluations mapped over 1D memory (or nested array rows), the standard mathematically intuitive `(i, j, k)` matrix multiplication loop pattern is highly inefficient due to cache misses. Changing to `(i, k, j)` provides massive speedups because the innermost loop sequentially accesses both destination row elements and the source weight row elements. However, since `(i, k, j)` implies accumulating values across iterations in the `k` loop, the output matrix elements must be zero-initialized before the inner loop starts (or initialized to the bias values) and care must be taken to maintain thread safety.
**Action:** Always inspect the loop traversal order in performance-critical numerical kernels to ensure the innermost loop accesses memory contiguously (row-major alignment).
