## 2025-05-18 - Conv2D Forward Pass Loop Hoisting and Row Caching **Learning:** In `Conv2DLayer::Forward`, calculating `ic * (H*W) + ih * W + iw` inside the innermost kernel loop caused 2D matrix indexing with `operator[]` bounds checking overhead and redundant index arithmetic on every kernel element. Hoisting spatial offsets out of the inner loops, caching single-row references, and applying `#pragma omp parallel for collapse(2)` on output channels and height produced a ~6.6x speedup. **Action:** Always hoist invariant stride and channel offsets and cache row array references before nested kernel convolution loops.
