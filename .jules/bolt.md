## 2024-05-15 - Matrix multiplication loop order
**Learning:** Changing the matrix multiplication loop order from `(i, k, j)` to `(i, j, k)` significantly improves CPU cache locality and enables better compiler vectorization, leading to faster performance. When using `(i, j, k)`, you must explicitly zero-initialize the output matrix `c` (e.g., `c.m_Data[i][k] = T(0);`) before accumulating values into it, as the Matrix class does not guarantee default zero-initialization. However, in `src/neural_network/neuronet.cpp`, the matrix multiplication within `NeuroNetLayer::CalculateOutput()` suffers from severe CPU cache misses when using the standard `(i, j, k)` loop order due to column-major memory access of `WeightMatrix[k][j]`. Reordering the loops to `(i, k, j)` resolves this by allowing contiguous, row-major access to both `OutputMatrix[i][j]` and `WeightMatrix[k][j]`, which yields substantial performance gains and auto-vectorization benefits.
**Action:** Reorder loops to (i, k, j) for matrix multiplication in `NeuroNetLayer::CalculateOutput()`.
